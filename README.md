# Code Hacker – Anuj Singh | Landing Page

A small, SEO-optimized landing page for the **Code Hacker** YouTube channel by **Anuj Singh**.
Built to rank on Google for searches like "anuj singh code hacker", "code hacker anuj singh", and "code hacker python termux".

## Files
- `index.html` — the page (SEO meta tags, Open Graph, JSON-LD structured data)
- `styles.css` — styling
- `og-image.png` — (add your own) 1200×630 social preview image

## Deploy in 2 minutes

### Option A — Vercel (recommended, free)
1. Push this folder to a GitHub repo (e.g. `code-hacker-landing`).
2. Go to https://vercel.com → **Add New → Project** → import the repo.
3. Framework preset: **Other**. No build command. Output dir: `/`.
4. Deploy. You'll get a URL like `https://code-hacker-landing.vercel.app`.
5. (Optional) Add a custom domain like `codehacker-anujsingh.com`.

### Option B — GitHub Pages (free)
1. Push this folder to a GitHub repo.
2. Repo → **Settings → Pages → Source: Deploy from a branch → main / (root)**.
3. Site goes live at `https://<username>.github.io/<repo>/`.

## After deploying
1. Update the `canonical` and `og:url` in `index.html` to your real URL.
2. Add an `og-image.png` (1200×630) for nice social previews.
3. Submit the URL to Google Search Console: https://search.google.com/search-console
   - Add property → URL prefix → verify via HTML file or DNS.
   - **URL Inspection → Request Indexing** for the homepage.
4. Link to this page from your Instagram bio, LinkedIn, and channel description to build backlinks.

## SEO tips
- Keep the title tag and H1 focused on "Code Hacker" + "Anuj Singh".
- Add new popular videos to the "Popular videos" section periodically.
- Update the subscriber/video counts as they grow.
- Consider adding a blog post per video (transcript + embed) for long-tail Google traffic.
